# Design direction — Round 1

- Typography is the focal point: monumental Geist name, tight headings, Instrument Serif for the more personal closing statements.
- Near-black / off-white ground, mint primary action, muted violet authentication material; light mode uses the same hierarchy with darker accent ink.
- Full-width editorial shell with 56px desktop / 20px mobile gutters; 8px spacing rhythm and an eight-step typography token scale.
- Hero leads with the name and security / identity / AI positioning; the orbital sculpture occupies a separate visual field with a static SVG fallback.
- Project visuals are explicitly labeled conceptual system illustrations, never presented as product screenshots.
- Motion belongs in interaction islands; content and links render on the server. Source links sit at the end of relevant entries.
- Public-source research omitted unsourced biography rather than filling requested sections with invented details. Writing uses five verified articles and three official LinkedIn embed references.
- Small-screen and reduced-motion project strips keep a native horizontal scrolling fallback; ordinary links remain available.
- Printed pages retain content, contact destinations, focus-independent structure, and pagination rules while hiding the live canvases.
- Current implementation gates: TypeScript clean, 339 unit tests passing, owned ESLint clean, formatted source. Root owns live visual/device/production gates and the public measured quality report.
